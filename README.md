# 3D Character Pipeline – выпускная квалификационная работа

Интерактивный веб-сайт для демонстрации сквозного пайплайна создания 3D-персонажей: от концепта до веб-интеграции с Three.js.

## Особенности
- Два персонажа (оленёнок и зайка) с полным ригом, блендшейпами эмоций и анимациями
- Переключение персонажа, загрузка своей GLB-модели
- Управление анимациями, скоростью, эмоциями
- Технические инструменты: каркас, скелет, UV-чекер, смена освещения
- Автотест блендшейпов

## Технологии
- Three.js, GSAP
- GLTF/GLB экспорт из Maya + Substance Painter
- GitHub Pages
